# satty001

A collection of projects, prototypes, and experiments. This repo is a living workspace that will continue to grow with new projects over time.

---

## Projects

### Clinical Trial Control Tower (`clinical-trial-tower/`)
An agentic AI platform demonstrating how 6 specialized AI agents could autonomously manage a clinical trial end-to-end. Built with Python/FastAPI on the backend and React/TypeScript on the frontend. Features include an Agent Mission Control stream, cinematic trial timeline, Spotlight command palette, and a synthetic data manufacturing module.

### ClinDev Tower Standalone (`clindevtower/`)
A standalone single-page HTML dashboard for the Clinical Trial Control Tower concept, styled with a Bain-branded design system. Includes interactive charts and a complete UI built without a framework.

### MacroHelix AI Implementation Triage (`backend/` + `frontend/`)
An intelligent pharmacy opportunity scoring and analysis tool. The Python/FastAPI backend provides scoring, sandbox, and governance APIs, while the React/TypeScript frontend delivers an interactive triage dashboard for evaluating pharmacy implementation opportunities.

### Tic-Tac-Toe (`tictactoe/`)
A simple Python tic-tac-toe game.
